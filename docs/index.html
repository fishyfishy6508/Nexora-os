Get Nexora OS ISO
The button opens the GitHub Actions build page. Sign in, open the latest successful run, scroll to Artifacts, and extract the ISO from its downloadable ZIP wrapper.

01 Build

Open the GitHub Actions workflow and run the ISO build, or choose the newest successful run.

02 Download

Under Artifacts, download NexoraOS-0.1.0-amd64-ISO and extract the genuine ISO image.

03 Boot

Mount the ISO in VirtualBox/VMware or flash it as an image to USB. Boot on BIOS or UEFI hardware.
